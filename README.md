# 💣 Campo Minado em C

Jogo Campo Minado desenvolvido em linguagem C, com interface gráfica utilizando a biblioteca Raylib.

O projeto tem como objetivo aplicar conceitos de lógica de programação, estruturas de dados e organização de código no desenvolvimento de um jogo interativo.

## Tecnologias utilizadas

- Linguagem C
- Biblioteca gráfica Raylib
- Visual Studio Code
- Programação estruturada

## Sobre o projeto

O Campo Minado é um jogo de lógica em que o jogador precisa descobrir as posições seguras de um tabuleiro, evitando as minas escondidas.

O desenvolvimento foi organizado em arquivos responsáveis pela lógica do jogo e pela interface gráfica.

## Estrutura do projeto

```text
campo-minado-c/
├── interface.c
├── jogo.c
├── jogo.h
├── LEIA-ME.txt
├── .gitignore
└── README.md
```

## Organização do código

**interface.c:** implementação da interface gráfica do jogo.

**jogo.c:** implementação da lógica e das regras do Campo Minado.

**jogo.h:** declarações compartilhadas, estruturas e funções utilizadas pelo projeto.

**LEIA-ME.txt:** informações complementares sobre o projeto.

## Como executar

1. Instale um compilador C compatível.
2. Configure a biblioteca Raylib no ambiente de desenvolvimento.
3. Abra os arquivos do projeto no editor.
4. Consulte o arquivo `LEIA-ME.txt` para verificar as orientações existentes.
5. Compile o projeto com a configuração adequada da Raylib e execute o programa gerado.

## Objetivo acadêmico

Projeto desenvolvido para praticar programação em C, lógica de programação e desenvolvimento de aplicações com interface gráfica.
